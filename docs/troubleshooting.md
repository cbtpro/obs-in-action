# 故障排查

[返回文档首页](./README.md)

| 现象 | 常见原因 | 处理建议 |
| --- | --- | --- |
| 启动时找不到前端证书 | `frontend/.ssl` 中缺少本地证书 | 按[快速开始](./getting-started.md#4-准备本地-https-证书)生成并信任证书 |
| 上传返回 40002/40003 | 类型不在对应场景白名单，或超过业务上限 | 对照[上传策略](./configuration.md#上传策略)检查文件和配置 |
| 上传直接返回 HTTP 413 | Spring 或前置代理的请求体上限先行拦截 | 同时检查 multipart 和代理限制 |
| 图片 URL 可见但无法显示 | 签名过期、mixed content、对象不存在或类型错误 | 刷新签名 URL，确认全链路 HTTPS 和对象状态 |
| 下载文件名是 UUID | 使用了对象直链，未经过代理下载响应 | 走带 `Content-Disposition` 的下载接口 |
| 删除记录后对象仍存在 | 处于软删除保留期，或清理任务未启用 | 检查 `deleted_at` 和 `file.cleanup` 配置 |
| 分片上传完成但合并失败 | 分片缺失、大小不一致或云端会话失效 | 重新 init，让服务端通过 `listParts` 对账 |
| 分片返回业务错误 40009 | `Content-MD5` 缺失、格式错误或与分片内容不一致 | 检查前端摘要计算和代理是否保留请求头 |
| 完成返回业务错误 40011 | 完整文件 SHA-256 与云端合并结果不一致 | 重新上传，并排查分片内容或客户端哈希计算 |
| 上传完成但日志提示“不加入秒传索引” | 后端无法通过配置域名下载刚合并的对象，常见于 TLS 证书域名不匹配 | 配置证书覆盖的 HTTPS 自定义域名；上传结果仍然有效 |
| 暂停后仍有少量网络流量 | 在途分片会收尾，不再领取新分片 | 属于当前暂停语义，不是取消失败 |
| 服务运行一段时间后请求超时 | 下载响应流未关闭，连接池逐渐耗尽 | 检查成功和异常路径是否都关闭流 |
| 切换 provider 后启动失败 | 新厂商配置不完整或 Bean 条件未命中 | 检查 `obs.provider` 和对应厂商配置 |

## 排查顺序

1. 确认请求是否到达后端；HTTP 413 往往发生在业务校验之前。
2. 根据响应错误码区分请求层、业务层和存储适配层错误。
3. 使用数据库会话状态判断流程阶段。
4. 对分片问题，以云端 `listParts` 结果为准，不以浏览器本地状态为准。
5. 检查清理任务是否显式启用，以及当前保留期是否已到。

## 提交问题时建议附带

- 使用的 provider 和 SDK 版本；
- 文件大小、服务端识别的 MIME 类型和上传入口；
- HTTP 状态码、业务错误码及脱敏日志；
- 会话状态和云端分片数量；
- 是否经过反向代理，以及相关请求体限制。

不要在日志或问题描述中粘贴 Access Key、Secret Key、签名 URL 的完整查询参数或数据库密码。
